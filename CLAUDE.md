# Nightlight

AI bedtime story studio for Fire TV (Vega OS, React Native). A parent and child build an illustrated, narrated story together; the child steers it with the remote, and it winds down toward sleep. Built for the Amazon Developer Hackathon 2026, Fire TV track.

The full plan, phases and API contract are in [PLAN.md](PLAN.md). Decisions are in [docs/decisions.md](docs/decisions.md), and friction goes in [docs/friction-log.md](docs/friction-log.md).

## Layout
- `apps/tv`: Vega OS React Native app (RN 0.83, `@amazon-devices/react-native-kepler`)
- `packages/shared`: API and event types shared by tv, companion and api
- `scripts`: repo scripts in TypeScript, run directly by Node 24 (no tsx)
- `docs/agent/adbt-steering.md`: ADBT steering doc (imported below); `.claude/skills/`: ADBT skills

## Commands
| Command | Does |
|---|---|
| `pnpm bootstrap` | install (frozen lockfile), create `.env`, run preflight |
| `pnpm preflight` | check Node, pnpm, Vega SDK, simulator, agent context, AWS (optional) |
| `pnpm tv:sim` | build the TV app, start the simulator if needed, install and launch |
| `pnpm tv:device` | same, on a connected Fire TV |
| `pnpm mock` | local mock API on :8787 (`tv:sim` forwards it to the device as `localhost:8787`) |
| `pnpm check` | lint + typecheck + tests (what CI runs) |

`pnpm setup`, `pnpm doctor` and `pnpm deploy` are **pnpm built-ins**, which is why our scripts are named `bootstrap`, `preflight` and `aws:deploy`.

## Conventions
- Look up Vega specifics with the ADBT MCP (`search_documentation` / `read_document`) before writing Vega code. Where ADBT and PLAN.md disagree, ADBT wins; record it in `docs/decisions.md`.
- Log every tool problem in `docs/friction-log.md` as you hit it (tried / expected / actual / severity / workaround).
- Exact dependency versions only (no `^`/`~`; `saveExact` is on). Toolchain pins live in `toolchain.json`.
- Scripts: Node built-ins only where possible, erasable TS syntax (no enums), `.ts` extensions in imports, cross-platform (no bash).
- pnpm settings go in `pnpm-workspace.yaml` (pnpm 12 ignores them in `.npmrc`). `nodeLinker: hoisted` is required by Metro and the Vega build.
- No third-party IP: only generated or original art, audio and characters.
- Keep the demo path working: the app must run on the simulator at the end of every phase.
- Remote keys: in `useTVEventHandler`, match both raw OS 1.2 and normalized names (`enter`/`select`, `play`, `forward`/`skip_forward`...) and act on key-down (`eventKeyAction === 0`). Back exits the app unless handled. See D-009.
